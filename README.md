# Kosuri Deepak Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

For a local development server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Before publishing
- Confirm MCA award status and exact completion date.
- Add a real GitHub profile URL.
- Add a repository or live demo for the Bank Webpage System if available.
- Review phone number and email before making them public.
- Update any wording that does not accurately represent Deepak's experience.

The banking dashboard shown in the project card is a decorative mockup, not a functional banking system.
